## 📖 Overview

IntelliFAQ is an AI-powered FAQ chatbot designed to answer questions related to Artificial Intelligence, Machine Learning, Natural Language Processing, Python, Data Science, and programming fundamentals.

The chatbot leverages Natural Language Processing (NLP) techniques such as TF-IDF Vectorisation and Cosine Similarity to identify the most relevant answer from a predefined FAQ knowledge base.

This project was developed as part of an AI internship project to demonstrate the practical implementation of NLP concepts in a user-friendly web application.

## 🧠 NLP Workflow

### Step 1: FAQ Dataset Creation

Questions and answers are stored inside:

```text
faq.csv
```

### Step 2: Text Vectorization

TF-IDF converts textual questions into numerical vectors.

### Step 3: Similarity Computation

Cosine Similarity compares the user's query against all FAQ entries.

### Step 4: Best Match Retrieval

The chatbot returns the answer corresponding to the most similar question.
