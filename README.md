# IntelliFAQ 🤖

IntelliFAQ is an AI-powered FAQ chatbot built using Python, Streamlit, TF-IDF Vectorization, and Cosine Similarity.

## Features

- Interactive chatbot UI
- FAQ matching using NLP
- AI, Python, ML, NLP, and Data Science knowledge base
- Modern dark-themed interface
- Deployable on Streamlit Cloud

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
